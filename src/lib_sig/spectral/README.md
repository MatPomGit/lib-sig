# spectral

Planowana analiza widmowa i czasowo-częstotliwościowa: FFT, periodogram, Welch PSD i spektrogram. Wymagane jawne parametry częstotliwości próbkowania, okna, długości FFT, overlap i normalizacji.

Wynik musi rozróżniać amplitudę, moc i gęstość widmową oraz ich jednostki. Reużywać sprawdzonych implementacji NumPy/SciPy, a nie pisać własny silnik FFT.
